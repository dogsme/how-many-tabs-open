## What it does

`main.py` writes one number, digits only, to `/output/entry.txt`: the
author's honest count of open browser tabs in their own browsing
session at build time.

The answer is **0**. When the count was taken (2026-11-23 22:43 UTC),
the author's browser had no windows open at all, so no tabs were open
either. Not a hoard, not a backlog, not a single lingering article:
a clean slate.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output file holds exactly the single digit `0`, with no trailing
newline.
